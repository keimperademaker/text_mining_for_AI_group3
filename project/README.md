Text Mining Final Project

This repository contains the code, data descriptions, results, and poster for our Text Mining final project.


The project focuses on three Natural Language Processing tasks:

1. Sentiment analysis
2. Topic classification
3. Named Entity Recognition and Classification (NERC)

For sentiment analysis and topic classification, we compared a traditional machine learning baseline with transformer-based models. For NERC, we evaluated a token-level entity recognition system using BIO tagging.
